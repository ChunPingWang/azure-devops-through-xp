# PointWallet XP 團隊 Wiki

## 系統隱喻（Metaphor）
> **點數錢包就像一個「存摺」**：每次消費是一筆「存入」、每次兌換是一筆「提領」、到期是一筆「沖銷」。餘額永遠等於所有存提紀錄的加總。

團隊在討論、命名類別與 API 時都使用這套共同語言（Wallet、Entry、earn、redeem、expire）。
